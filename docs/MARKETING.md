# MARKETING — Drama Studio

Première version créée le 21 août 2026 (statut réel — aucun chiffre inventé).
Le produit à promouvoir n'est pas l'application (outil interne) mais les
**séries de micro-dramas** qu'elle produit, prêtes à publier (MP4 verticaux,
nom de fichier = titre + hashtags).

## Modèle de rémunération

| Modèle | Statut |
| --- | --- |
| Aucune monétisation directe — construction d'audience d'abord | ✅ actuel |
| Programme de récompenses créateurs TikTok (vidéos > 1 min : Format long à privilégier) | ⬜ envisagé |
| Monétisation YouTube Shorts | ⬜ envisagé |
| Placements / sponsors locaux dans les épisodes | ⬜ envisagé |
